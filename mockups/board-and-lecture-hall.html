In VRChat

The board

  • Events come from one GitHub Pages file; only the world's owner adds events. No re-upload to change the board.
  • The board refreshes on join and every 15 to 30 min, sharing the one-download-per-5-s budget with books.
  • Times are stored in UTC and shown in each visitor's local time.
  • The world can't see other instances, so the board lists scheduled events, not live instances elsewhere. "Lecture live in this instance" is the only live line.
  • The Doghouse Devs button opens the group page; no other world is promoted on the board.

The lecture hall

  • Presenter rights use VRChat's instance owner. Group instances have no owner, so "host" falls back to the instance master unless the SDK exposes group roles (still to verify).
  • Pictures load only for visitors with untrusted URLs on. The media player is VRChat's video player; only hosts, the owner and the presenter can enter URLs.
  • The stage voice boost is the presenter's voice range, raised while they stand on the stage.
  • Network IDs: adds a few synced objects (stage, screen state, media sync). PC and Quest must match. Late joiners see the current page, picture or video moment at once.
  • Lectern look: A3 Candlelit, the same page as the 04 lecterns.

Hands, desktop, Quest

  • VR: point at board rows and console buttons and pull the trigger. Desktop: walk up and click. Phone: the simpler board, tapped.
  • Quest cost: low for the board and the page; the video player is the heaviest part, and only plays when a host loads something.

Builds on

  • The 04 lecterns: the Candlelit page, the shared page with highlight and follow-link, hand-over, and the small search stand (same search shards and aliases as the big catalog).
  • Books fetched from GitHub Pages with the ~5 s load hidden behind animation; the events file uses the same fetch.
  • Clickable gold words (overlay hit areas over the words).
  • The arena's TV board idea: one remote events file, no re-upload.
